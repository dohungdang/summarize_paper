Frontend - Dự án Txt

Phần giao diện người dùng được xây dựng bằng HTML, CSS và JavaScript.

Chức năng:
- Nhập văn bản cần tóm tắt
- Hiển thị kết quả tóm tắt
- Sao chép và xóa nội dung
- Hiển thị lịch sử tóm tắt
- Giao diện đăng nhập cơ bản

Giao diện thân thiện, dễ sử dụng và chạy trực tiếp trên trình duyệt.
